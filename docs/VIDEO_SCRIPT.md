# Three-minute demo video script

**Target runtime:** 2 minutes 40 seconds.  
**Recording goal:** show one complete seller-to-buyer story using a fresh test listing and PayPal Sandbox.

## Before recording

- Use a fresh listing that has not been purchased before.
- Confirm the Vercel environment variables are working and the live site loads.
- Use a PayPal **Sandbox** buyer account only. Never show a real address, card, password, API key, or test-account password in the video.
- Have four clear photos of one real secondhand item ready.
- Start with an empty bag. Keep the GitHub repository and a clean browser tab available for the final shot.
- Do one practice checkout first only if you can create another fresh listing for the final recording. A captured item becomes sold.

## Shot list and voiceover

| Time | Screen action | Voiceover |
| --- | --- | --- |
| 0:00–0:12 | Open the Found Again home page. Slowly show the storefront. | “Every secondhand item is one of one. That makes selling it time-consuming, and buying it uncertain. Found Again Market helps good things find their next beginning with AI assistance and PayPal.” |
| 0:12–0:25 | Open **Sell**. Add the photos and a few honest notes. | “A seller starts with photos and only the details they know: category, price, and a short honest note.” |
| 0:25–0:48 | Click **Generate AI draft**. Show the draft, price range, and AI photo check. | “The AI uses the seller’s notes and the photos to prepare an editable listing draft. It calls out only details it can clearly see, so the seller can check for visible wear before publishing.” |
| 0:48–1:02 | Edit or confirm the draft, then publish. Return to the shop and open the new item. | “AI does not publish on the seller’s behalf. The seller remains the editor, then chooses when the one-of-one item goes live.” |
| 1:02–1:32 | Open the guide. Type: “I need a cozy gift under $25.” Show its proposed items, names, and exact total. | “On the buyer side, a shopper can ask in plain language. The guide reads the current catalog and proposes an in-stock option with an exact, visible price.” |
| 1:32–1:44 | Show “Nothing added yet,” then click **Add this find** or **Add these finds**. Show the bag. | “The guide can recommend, but it cannot alter the bag or start a payment. The buyer explicitly approves the proposal first.” |
| 1:44–2:12 | Click checkout. Briefly show the PayPal Sandbox approval screen, then complete payment. Do not show any credentials. | “At checkout, the server reads the trusted product price and creates a PayPal order. PayPal handles the buyer approval in Sandbox; Found Again never collects card details.” |
| 2:12–2:32 | Return to Found Again. Show the receipt and the item’s sold state. | “When PayPal confirms capture, the item is marked sold and the buyer receives a receipt view. The app reserves an item for ten minutes during checkout, so a one-of-one find is not sold twice.” |
| 2:32–2:50 | End on the home page or GitHub README, then the Found Again logo/name. | “Found Again makes the secondhand journey more honest, more personal, and safer to complete. AI proposes; people decide; PayPal completes the purchase.” |

## Recording notes

- Keep cursor movement deliberate and pause one second after each important state change.
- If the guide proposes a different item than expected, use the actual proposal; do not stage a claim the app did not make.
- It is fine to cut between screens. The story should feel like one continuous journey, not a raw unedited test.
- Add captions for the key trust statements: **seller confirms**, **buyer approves**, and **PayPal completes payment**.
- Record at least 1080p if possible. Keep the final public YouTube upload under three minutes.

## Suggested title and video description

**Title:** Found Again Market — AI-assisted secondhand marketplace with PayPal

**Description:** Found Again Market helps people rehome one-of-one secondhand finds. Sellers use AI to create an editable, photo-aware listing draft; buyers receive transparent recommendations and explicitly approve every cart action. PayPal Sandbox completes checkout while the app protects one-of-one inventory with a short reservation and server-side sold state.
